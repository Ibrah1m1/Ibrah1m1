## 🌐 About This Repository (`Ibrah1m1/Ibrah1m1`)

In addition to serving as my GitHub Profile README, this repository houses the source code for my **personal portfolio web application**, published live via **GitHub Pages**.

### 🌟 Key Portfolio Features
- **Zero-Dependency Vanilla Stack**: Extremely fast load times and minimal footprint built with pure semantic HTML5, modern CSS3, and vanilla ES6+ JavaScript.
- **Glassmorphic UI**: Frosted glass navigation with `backdrop-filter: blur(24px)`, adaptive borders, and floating depth.
- **Dynamic Dark/Light Mode**: Seamless color mode transitions with state persisted in `localStorage` and custom SVG sun/moon icons.
- **Scroll-Linked SVG Logo Animation**: Interactive 3D perspective transform of a custom monogram logo dynamically tied to scroll offset.
- **Embedded Interactive Prototypes**: Direct embedding of Figma prototypes with responsive aspect ratio handling.
- **Scroll Progress Tracker**: Fixed-position real-time page reading indicator.

## 🏗️ Architecture & Project Structure

```text
Ibrah1m1/
├── index.html        # Main semantic markup, SVG definitions, and app logic
├── style.css         # CSS design tokens, glassmorphism, responsive styles
├── README.md         # Profile overview & codebase documentation
└── .git/             # Git version control metadata
```

### Architecture Highlights
- **Design Tokens**: Centralized in `:root` and `body.dark` with CSS custom properties (`--bg`, `--ink`, `--silver`, `--glass-bg`, etc.).
- **Progressive Enhancement**: Clean fallback for non-JS environments while enhancing with smooth transitions and interactive listeners.
- **Accessible Interactions**: Contrast-checked color ratios, semantic HTML landmarks, and keyboard-navigable controls.

## 💻 Local Setup & Development

Follow these simple steps to run the portfolio locally on your machine:

### 1. Clone the Repository
```bash
git clone https://github.com/Ibrah1m1/Ibrah1m1.git
cd Ibrah1m1
```

### 2. Run Locally

Because this project is built with vanilla web technologies, no build step or package installation (`npm install`) is required:

#### Option A: Python 3 (Recommended)
```bash
python3 -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

#### Option B: VS Code Live Server
1. Open the folder in VS Code.
2. Right-click `index.html` and select **"Open with Live Server"**.

#### Option C: Node / npx
```bash
npx serve .
```

## 🚀 Deployment (GitHub Pages)

This repository is configured to deploy automatically via GitHub Pages:

1. Navigate to **Settings** > **Pages** in the repository.
2. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
3. Set the branch to `main` (or your release branch) and folder to `/(root)`.
4. Click **Save**. The site will be live at `https://<username>.github.io/<repository>/`.
